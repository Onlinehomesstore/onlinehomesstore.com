# Online Homes Store — Demo Catalog

Import these files into Shopify Admin to populate the baby toys storefront.

## 1. Collections

Admin → Products → Collections → Import  
Or create manually using handles in `collections.csv`.

## 2. Products

Admin → Products → Import → upload `products.csv`

Image URLs point to Unsplash (free license) so Shopify downloads them during import.

## 3. Navigation

Admin → Online Store → Navigation → **main-menu**

Suggested structure:

- Home → `/`
- Shop All → `/collections/all`
- Baby Toys → `/collections/baby-toys`
- Educational Toys → `/collections/educational-toys`
- Sensory Toys → `/collections/sensory-toys`
- Wooden Toys → `/collections/wooden-toys`
- Soft Toys → `/collections/soft-plush-toys`
- New Arrivals → `/collections/new-arrivals`
- Best Sellers → `/collections/best-sellers`
- Gifts → `/collections/perfect-little-gifts`

## 4. Theme images

Theme assets prefixed `ohs-*.jpg` power homepage fallbacks when Theme Editor images are empty.
